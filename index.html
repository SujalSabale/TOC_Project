Problem Statement & Formal Context

The language under study is defined as:

$$L = \{a^n b^n \mid n \ge 1\} = \{ab, aabb, aaabbb, aaaabbbb, \dots\}$$

It represents all strings consisting of a non-zero sequence of symbol a followed immediately by an equal number of symbol b.

Key Chomsky Hierarchy Classification:
  • Type-3 (Regular Languages): ❌ Cannot recognize $L$ (no memory/counting mechanism).
  • Type-2 (Context-Free Languages): ✔ Recognized by non-deterministic and deterministic Pushdown Automata (PDA) using a single LIFO stack.
  • Type-1 / Type-0 (Context-Sensitive / Recursively Enumerable): ✔ Recognized by Linear Bounded Automata (LBA) and Turing Machines (TM).
02

Mathematical Proof: Why Finite Automata (DFA/NFA) Fail

To prove that $L = \{a^n b^n \mid n \ge 1\}$ is not regular, we use the Pumping Lemma for Regular Languages via proof by contradiction.

Theorem (Pumping Lemma for Regular Languages):

If $L$ is a regular language, then there exists a constant integer $p \ge 1$ (the pumping length) such that any string $s \in L$ with length $|s| \ge p$ can be partitioned into three substrings $s = xyz$ such that:

  1. $|y| > 0$ (the pumped substring is non-empty)
  2. $|xy| \le p$ (the pumped substring lies within the prefix of length $p$)
  3. For all $i \ge 0$, $x y^i z \in L$.

Step-by-step Contradiction Proof:

1. Assumption: Assume for contradiction that $L = \{a^n b^n \mid n \ge 1\}$ is regular.

2. Pumping Length: Let $p$ be the pumping length guaranteed by the Pumping Lemma.

3. Choice of String: Choose the string $s = a^p b^p$. Notice that $s \in L$ and $|s| = 2p \ge p$.

4. Decomposition: By Condition 2 ($|xy| \le p$), the substring $xy$ must consist exclusively of the prefix $a^p$. Therefore, $y$ can only contain the symbol $a$. We can write:

$$y = a^k \quad \text{for some } k \ge 1 \text{ (since } |y| > 0\text{)}$$

5. Pumping with $i = 2$ (or $i = 0$): Consider the pumped string $s' = x y^2 z$:

$$s' = x y y z = a^{p-k} a^{2k} b^p = a^{p+k} b^p$$

6. Contradiction: In $s'$, the number of symbol $a$'s is $p+k$, but the number of symbol $b$'s is $p$. Since $k \ge 1$, $p+k \ne p$. Therefore, $s' \notin L$, which directly violates Condition 3 of the Pumping Lemma!

Conclusion: The assumption that $L$ is regular is false. Hence, $L$ is not regular and cannot be recognized by any DFA or NFA.

Formal Mathematical 7-Tuple Definitions

Turing Machine 7-Tuple

$M = (Q, \Sigma, \Gamma, \delta, q_0, B, F)$

  • $Q$ (States): $\{q_0, q_1, q_2, q_3, q_{\text{accept}}\}$
  • $\Sigma$ (Input Alphabet): $\{a, b\}$
  • $\Gamma$ (Tape Alphabet): $\{a, b, X, Y, B\}$
  • $\delta$ (Transition Function): $\delta: Q \times \Gamma \to Q \times \Gamma \times \{L, R\}$
  • $q_0$ (Initial State): $q_0$
  • $B$ (Blank Symbol): $B$
  • $F$ (Final/Accepting States): $\{q_{\text{accept}}\}$

Pushdown Automaton 7-Tuple

$P = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)$

  • $Q$ (States): $\{q_0, q_1, q_2, q_f\}$
  • $\Sigma$ (Input Alphabet): $\{a, b\}$
  • $\Gamma$ (Stack Alphabet): $\{A, Z_0\}$
  • $\delta$ (Transition Function): $\delta: Q \times (\Sigma \cup \{\epsilon\}) \times \Gamma \to \mathcal{P}(Q \times \Gamma^*)$
  • $q_0$ (Initial State): $q_0$
  • $Z_0$ (Initial Stack Symbol): $Z_0$
  • $F$ (Final States): $\{q_f\}$

Examiner Viva & Interview Preparation Guide

Q1: Why can't a Finite Automaton recognize $L = \{a^n b^n \mid n \ge 1\}$?
A Finite Automaton has a strictly finite set of internal states (no external memory or stack). To recognize $a^n b^n$, it must count an arbitrarily large number of symbols $a$ to ensure an identical number of symbols $b$ follow. Since $n$ can be arbitrarily large (e.g., $n = 10^9$), by the Pigeonhole Principle the automaton will be forced to loop into already visited states and lose the exact count of symbol $a$.
Q2: Why is the time complexity of the 1-Tape Turing Machine $O(n^2)$ for this language?
For each symbol $a$ that the TM marks as $X$, the tape head must traverse all remaining symbol $a$'s and existing $Y$'s to find and cross the matching $b$ with $Y$ (distance roughly $2n$). Then the head must rewind all the way back to the left $X$. This round-trip takes $O(n)$ steps per matching pair. Since there are $n$ pairs, the total time is $O(n \times n) = O(n^2)$.
Q3: How does a Pushdown Automaton achieve $O(n)$ time complexity?
A PDA processes the input string from left to right in a single linear pass. Each symbol $a$ is pushed onto the stack in $O(1)$ time, and each symbol $b$ pops an $a$ in $O(1)$ time. At the end, a single check verifies that the stack contains only the bottom marker $Z_0$. Thus, total operations $= 2n$ transitions, resulting in optimal $O(n)$ linear time.
Q4: Why does the problem specify $n \ge 1$ instead of $n \ge 0$?
When $n \ge 0$, the empty string $\epsilon$ ($a^0 b^0$) belongs to the language. When $n \ge 1$, $\epsilon$ must be rejected. In our Turing machine, if the initial symbol under the head is Blank ($B$), it halts in a non-accepting state, correctly rejecting $\epsilon$.
